# **App Name**: TaskMaster

## Core Features:

- Task Creation: Allow users to add new tasks to their to-do list.
- Task Listing: Display all active tasks with their descriptions and due dates.
- Task Completion: Enable users to mark tasks as complete, removing them from the active list.
- Task Editing: Allow users to edit existing tasks to update descriptions or due dates.

## Style Guidelines:

- Primary color (Light Theme): Light blue (#5DADE2) to evoke calmness and focus.
- Background color (Light Theme): Very light blue (#EBF5FB), a desaturated version of the primary color, to keep a consistent but subtle appearance.
- Accent color (Light Theme): Purple (#A569BD) for task highlighting and calls to action, differing from the primary color in brightness and saturation.
- Primary color (Dark Theme): Dark gray (#34495E) to provide a comfortable viewing experience in low-light environments.
- Background color (Dark Theme): Black (#2C3E50) to reduce eye strain and provide high contrast.
- Accent color (Dark Theme): Light purple (#9B59B6) for task highlighting and calls to action, offering vibrancy against the dark backdrop.
- Font: 'Inter', a grotesque-style sans-serif font for both headings and body text, because the app has limited amounts of text and a font pairing is unneccesary. It has a modern, objective, and neutral look to provide a clean reading experience.
- Use clear, minimalistic icons for task actions (add, edit, complete) and status indicators.
- Clean, list-based layout to facilitate task management, focus on the user's tasks, and promote simplicity. Make all main functions accessible from the main view.
- Smooth transitions for adding, completing, and editing tasks to provide visual feedback.
- Include a toggle for switching between light and dark themes, positioned in an easily accessible location (e.g., top right corner).
